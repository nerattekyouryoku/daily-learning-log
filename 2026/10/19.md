## Key concepts
- OSI model is theoretically good network standard but not good for acutual use (7 layer)
- TCP/IP model is 5 layers consisting of physical layer, data link layer, network layer, transport layer, application layer (4 layer is also present)
- Full duplex means it is allowed to send and receive at the same time
- Half duplex means not at the same time
- autonegotiation automatically match the speed and duplex
- CSMA/CD (Career sense multiple access collision detection) avoids the collision between half duplex
- HTML is Hypertext Markup Language, which build blocks, which use element and attributes
- CSS is Cascading style sheet, which style the thing I made in HTML, and which has three ways - 1. inline 2. internal 3. external
